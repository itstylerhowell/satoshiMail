New web service: obtain dump of bitcoin block NNNN

BitcoinTalk forum · 4 messages · from 26 August 2010 · with Satoshi Nakamoto, jgarzik, nelisky

Read in Satoshi Mail Archive source

jgarzik · 26 August 2010, 00:21 UTC · original
As part of Bitcoin Watch <http://www.bitcoinwatch.com/>, a new feature provides a developer-friendly dump of a bitcoin block at the specified height. GET parameters: "h" - height of block to download "json" - set to non-zero value, to enable application/json output rather than HTML output Examples: Dump block 72000: http://blk.bitcoinwatch.com/b?h=72000 Dump block 72000, with JSON: http://blk.bitcoinwatch.com/b?h=72000&json=1
jgarzik · 27 August 2010, 07:22 UTC · original
This sub-page of Bitcoin Watch shows the last 7 days worth of blocks, each block linking to expanded data: http://blk.bitcoinwatch.com/
