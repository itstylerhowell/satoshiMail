Oh great, now we're screwed. We probably got spam blocked because we were allowing registrations without e-mail verification. But now that we've enabled it, our verification e-mails are blocked. There could still be some existing user accounts created before the registration requirement being used by spammers. We're kind of in a jam here. Can you make sure there's nothing else you can think of that might be acting as an open e-mail gateway or way for spammers to use our system for putting out spam? Check the e-mail logs and see if there's been a lot of traffic and what it's from. If you can figure out what the problem was and shut it down, then after you're sure it's fixed, request PBL to take us off the block list.
