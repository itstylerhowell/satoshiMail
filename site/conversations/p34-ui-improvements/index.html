UI improvements

BitcoinTalk forum · 7 messages · from 21 February 2010 · with Sabunir, Satoshi Nakamoto, Xunie, giik, sirius

Read in Satoshi Mail Archive source

Satoshi Nakamoto · 21 February 2010, 21:48 UTC · original
Uploaded some UI changes to SVN as version 0.2.5. Instead of View->Show Generated, we now have tabs: - All Transactions - Sent/Received - Sent - Received Makes it a lot easier to flip to received and check for payments. Moved the "Your Addresses" book inside the main address book.  It was confusing having two address books. I found the "To:" in "From: unknown, To: (one of your bitcoin addresses)" still confusing, so I changed it to "From: unknown, Received with:".  The bitcoin address is abbreviated so you can see the label that you set in the Receiving tab of the address book. Fixed a few UI glitches from the upgrade to wxWidgets 2.9.0. I haven't forgotten about you people who want non-UI, but I had to do some fun stuff before more build bashing.

I think he had it working on FreeBSD, but he wanted a non-UI version. I have the command line and JSON-RPC daemon version working now.  Will SVN it in a day or two. I disabled gdm on my Ubuntu system so it boots into command line.  I hope I will be able to get it enabled again with rcconf.
