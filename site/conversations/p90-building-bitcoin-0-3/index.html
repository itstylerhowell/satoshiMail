laszlo · 12 July 2010, 20:42 UTC · original
Looks like your wxWidgets and STL - you should compile your own wxWidgets from the 2.9 release. Use something like this to configure it and adjust the reference paths in your makefile.unix
Quote
mkdir buildgtk cd buildgtk ../configure --prefix=/home/my_user/bitcoin/deps \ --with-gtk \ --disable-shared \ --disable-debug_flag \ --enable-stl \ --enable-utf8 \ --with-libjpeg=builtin \ --with-libpng=builtin \ --withregex=builtin \ --with-libtiff=builtin \ --with-zlib=builtin \ --withexpat=builtin
Satoshi Nakamoto · 14 July 2010, 17:34 UTC · original
