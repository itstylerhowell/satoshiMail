Warning: don't use -server or bitcoind where you web browse (v0.3.2 and lower)

BitcoinTalk forum · 11 messages · from 19 July 2010 · with Axcella, Gavin Andresen, Quantumplation, Satoshi Nakamoto, franzl, fresno…

Read in Satoshi Mail Archive source

Satoshi Nakamoto · 19 July 2010, 16:01 UTC · original · satoshin.name
Don't use the -server or -daemon switch or run bitcoind on a machine where you use a web browser.  It opens port 8332 on 127.0.0.1, the local loopback address, and you wouldn't think that web browsers could cross-site access it, but it is possible. We're working on a release soon that puts a password on the JSON-RPC interface, but until then, avoid using the -server switch, and don't web browse on the same machine where bitcoind is running. Update: The JSON-RPC HTTP authentication feature in 0.3.3 solves this problem.

Gavin Andresen · 21 July 2010, 15:01 UTC · original
You can still generate bitcoins, just don't run bitcoind or bitcoin -server or bitcoin -daemon on machine that you use to browse the Web. As sirius says, if you do you could browse to a website that empties your Bitcoin wallet without your knowledge or permission.
