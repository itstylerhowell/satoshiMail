dkaparis · 13 July 2010, 22:22 UTC · original
Are you by any chance using Microsoft Security Essentials or 'Live Protection' antivirus program? It is known to interfere with bitcoin's operation, see here: http://bitcointalk.org/index.php?topic=35.0
dkaparis · 13 July 2010, 22:51 UTC · original
It should be enough to just add bitcoin.exe to the "Excluded processes" list in settings. It is a good idea to add this to the FAQ somewhere.

Satoshi Nakamoto · 14 July 2010, 18:02 UTC · original
This is the second time I've seen this "Live Protection" problem reported. It must be blocking the program's network communication.  It sounds like it's allowing connections to be made, hence the 10 connections shown, but not allowing any data to be sent or received on them. We need to understand this problem better. Can someone write some instructions on the wiki explaining how to turn off or add an exclusion to Live Protection or whatever its full proper name is.
