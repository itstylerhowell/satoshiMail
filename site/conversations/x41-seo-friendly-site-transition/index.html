SEO friendly site transition

Private email with Martti Malmi (sirius-m) · 2 messages · from 22 November 2009 · with Satoshi Nakamoto, mmalmi@cc.hut.fi

Read in Satoshi Mail Archive source

Satoshi Nakamoto to Martti Malmi <mmalmi@cc.hut.fi> · 22 November 2009, 19:47 UTC · original
We need to do a continuity transition with bitcoin.org so the search engines don't think this is a new site and reset the site start date and PR data. Google allows a certain number of properties like IP address or content of the site to change without deleting your site history. To play it safe, when the IP address changes, the content better stay the same and vice versa. Even though not much rank has accumulated yet, the original start date becomes extremely important if the site gets popular later. Steps: 1) copy the current bitcoin.org index.html to the new server exactly as-is. 2) switch the bitcoin.org DNS entry. 3) keep working on the drupal site behind the scenes. 4) after google has had time to update its records, we can switch over to the drupal site. The timing works out well because we can switch to the new forum now and release the drupal site later when we're ready. I'll see if I can figure out how to temporarily move drupal aside to drupal.php or /drupal/ or something where we can still easily get in and work on it.
mmalmi@cc.hut.fi to Satoshi Nakamoto <satoshin@gmx.com> · 22 November 2009, 20:22 UTC · original
