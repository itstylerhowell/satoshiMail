BSD detection

BitcoinTalk forum · 4 messages · from 11 August 2010 · with Satoshi Nakamoto, dkaparis

Read in Satoshi Mail Archive source

dkaparis · 11 August 2010, 23:00 UTC · original
There is this piece of code in headers.h: #ifdef __WXMAC_OSX__ #define __WXMAC__ 1 #define __WXOSX__ 1 #define __BSD__ 1 #endif #endif In my testing it's not caught on FreeBSD 8.1 I propose it be changed to: #if (defined(__unix__) || defined(unix)) && !defined(USG) #include <sys/param.h> #endif And then checks for BSD should be #ifdef BSD This is the recommended way of detecting BSD in the FreeBSD Porter's Handbook <http://www.freebsd.org/doc/en/books/porters-handbook/porting-versions.html>. This change is already done in my CMake tree.

There is this piece of code in headers.h: #ifdef __WXMAC_OSX__ #define __WXMAC__ 1 #define __WXOSX__ 1 #define __BSD__ 1 #endif #endif
That code was a bad idea anyway, I'm deleting it.  Any Mac code should only use __WXMAC_OSX__, not __WXMAC__ or __WXOSX__, and we should stop using __BSD__.

Satoshi Nakamoto · 12 August 2010, 21:14 UTC · original
This is in SVN rev 130.  Check that it compiles right.
#if (defined(__unix__) || defined(unix)) && !defined(USG)
#include <sys/param.h>  // to get BSD define
#endif
#ifdef __WXMAC_OSX__
#ifndef BSD
#define BSD 1
#endif
#endif
