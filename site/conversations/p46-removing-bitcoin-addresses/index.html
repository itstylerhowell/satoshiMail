removing bitcoin addresses

BitcoinTalk forum · 3 messages · from 8 April 2010 · with Satoshi Nakamoto, SheriffWoody, sirius

Read in Satoshi Mail Archive source

SheriffWoody · 8 April 2010, 14:56 UTC · original
Is there any way to remove bitcoin addresses that you have generated for yourself? What about if you have received payments to those addresses? Are they needed to show ownership for the coins after they have been transferred?
sirius · 10 April 2010, 06:12 UTC · original
A question to Satoshi: have you tested the program with thousands of own addresses in the wallet? If I make a new address for each automated transaction, it's going to be a big amount. Or maybe I could reuse the addresses, given a big enough pool.
Satoshi Nakamoto · 16 May 2010, 23:34 UTC · original
SheriffWoody: Bitcoin addresses you generate are kept forever.  A bitcoin address must be kept to show ownership of anything sent to it.  If you were able to delete a bitcoin address and someone sent to it, the money would be lost.  They're only about 500 bytes. sirius-m: Thousands of own addresses should not be any problem at all.  If you've generated 50000 BTC, then you already have 1000 own addresses, one for each 50 generated.  Those are hidden, they're not shown in the UI. It would be a good idea to add a little code that keeps giving the same address to the same IP.  Here's what I did in C++ to keep giving the same key (aka bitcoin address) until they use it:     // Keep giving the same key to the same ip until they use it     if (!mapReuseKey.count(pfrom->addr.ip))         mapReuseKey[pfrom->addr.ip] = GenerateNewKey();          ...sends the key mapReuseKey[pfrom->addr.ip] ...later...     // Received something with this key     mapReuseKey.erase(pfrom->addr.ip); If it's not convenient to know when you've received, just clear the cached keys every 20 minutes. I want to add a parameter to getnewaddress for number of days to expire if nothing is received with the address.
