The Madhatter · 15 April 2010, 00:49 UTC · original
I have the latest SVN snapshot running on FreeBSD (bitcoind) with automation running on a few servers. You just install databases/db48, x11-toolkits/gtk20, devel/gmake, and devel/boost-all from the ports tree, download wxwidgets 2.9 and install it manually (the port version is 2.8.. that's no good), change a few paths in the makefile.unix file, and run "gmake -f makefile.unix bitcoind". You will end up with a binary called "bitcoind" (it is headless). Run "strip ./bitcoind" to make it smaller (it is really big with the debugging symbols). You can, of course, leave the debugging symbols in. I had to use gdb on bitcoind a few times in the past to figure out a strange crash. I have tested bitcoind on 32 and 64 bit systems running FreeBSD. I didn't detect any memory leaks or see any crashes.
