Pre-release source code

Satoshi's November 2008 code

Date
November 2008
Recipients
Hal Finney, Ray Dillinger, James A. Donald

In November 2008, two months before the first release, Satoshi sent the core of his source code to three people from the Cryptography mailing list: Hal Finney, Ray Dillinger and James A. Donald. Finney's reply, copied to the other two, is in this archive (the email).

Dillinger later published the main files on BitcoinTalk, and nakamoto-archive keeps a copy.[1]
