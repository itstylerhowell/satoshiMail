nakamoto-archive is a GitHub repository that collects Satoshi's writings together with the primary sources they come from: mailing-list archives, the email collections of Martti Malmi, Mike Hearn, Dustin Trammell and Hal Finney, the emails with Adam Back and Wei Dai, early code, and an early version of bitcoin.org.[1] Each source file is listed with its date, origin and SHA-256 hash.

Satoshi Mail's Private tab is built from it (open Private).
