SourceForge

Bitcoin's first code host

Repository
Subversion (SVN)
Satoshi's last revision
r202, 15 December 2010

Bitcoin's first home was SourceForge, which hosted the downloads, the bitcoin-list mailing list and a Subversion repository. Satoshi committed as s_nakamoto; the first revision credited to him is r15 on 21 October 2009 (r15) and his last is r202, “get external ip from irc”, on 15 December 2010 (r202). The archive lists 203 commits under his name (open Commits).

The SVN history was later imported into the Git repository on GitHub that became Bitcoin Core.[1]
