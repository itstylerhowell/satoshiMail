Bitcoin Core

The continuation of Satoshi's client

Renamed
2014 (version 0.9.0)
Repository
github.com/bitcoin/bitcoin

Bitcoin Core is the software Satoshi first published under the name “Bitcoin”; it took the name Bitcoin Core with version 0.9.0 in 2014.[1] Its GitHub repository holds the full history back to the SourceForge era, including all of Satoshi's commits.[2]

After Satoshi stepped back, Gavin Andresen led development until Wladimir J. van der Laan took over as lead maintainer on 8 April 2014.[1] Satoshi's last commit is SVN revision 202 (“get external ip from irc”); the 203 commits listed under his name are in the Commits folder of Satoshi Mail (open Commits).
