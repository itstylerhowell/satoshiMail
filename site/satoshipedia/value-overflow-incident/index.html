Value overflow incident

Block 74638, 15 August 2010

The value overflow incident was a bug found on 15 August 2010, when a transaction in block 74638 used an integer overflow to create bitcoins out of nothing: two outputs of 92,233,720,368.54 BTC each (the forum report). The bug was fixed within hours.[1]

Response

Satoshi posted an alert within hours: “*** WARNING *** We are investigating a problem. DO NOT TRUST ANY TRANSACTIONS THAT HAPPENED AFTER 15.08.2010 17:05 UTC (block 74638) until the issue is resolved.” (the alert). He committed the fix the same day (“fix for block 74638 overflow output transaction”) and released version 0.3.10, which rejected the bad block (the release post).

Satoshi asked users to stop generating so a corrected branch could overtake the bad one. The next day he wrote: “It looks like we overtook the bad chain somewhere around 74689”, and added code to reorganise the chain automatically (the thread).

Aftermath

A week later Satoshi began building an alert system so that developers could warn every node of an emergency (the post). He later handed the alert key to Gavin Andresen.
