Bitcoin v0.1 was the first release of Satoshi's software. He announced it on the Cryptography mailing list on 8 January 2009: “Announcing the first release of Bitcoin, a new electronic cash system that uses a peer-to-peer network to prevent double-spending.” It ran on Windows only for the time being and included the C++ source code (the announcement).

The release notes on bitcoin-list set out the rules that still apply, including the 21 million coin limit (release notes; see 21 million supply cap).

First users

Hal Finney ran it immediately, and Satoshi sent him the first transaction on 12 January. Within days Finney, Dustin Trammell and others were reporting bugs, and Satoshi shipped versions 0.1.2, 0.1.3 and 0.1.5 over the following weeks (v0.1.2). He also wrote to Wei Dai that the release “achieves nearly all the goals you set out to solve in your b-money paper”.
