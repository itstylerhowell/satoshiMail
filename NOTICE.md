# Third-party content and names

The MIT license in [LICENSE](LICENSE) covers the code and design of Satoshi Mail,
Satoshipedia and Satoshi Map, written by Tyler Howell. It does **not** cover the
material the archive is made of, which keeps its own terms:

| Material | Where it comes from | Terms |
|---|---|---|
| Satoshi's emails and forum posts, and the replies around them | [Satoshi Nakamoto Institute](https://satoshi.nakamotoinstitute.org/) | Much of the Institute's content is CC BY-SA 4.0; library documents vary. Each message links to its source. |
| Private correspondence and source files | [nakamoto-archive](https://github.com/lugaxker/nakamoto-archive) | See that repository; each file lists its original source. |
| Satoshi's commits and their diffs | [bitcoin/bitcoin](https://github.com/bitcoin/bitcoin) | MIT (Bitcoin Core's license). |
| The white paper | [bitcoin.org](https://bitcoin.org/bitcoin.pdf) | See bitcoin.org. |
| Satoshipedia article text | Written for this project, summarising and quoting Wikipedia and the sources above | Shared under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), because it draws on Wikipedia. |
| satoshin.name cross-check | [Satoshi Nakamoto Archive](https://satoshin.name/) | Only links to its pages (`tools/satoshipedia/satoshin_xref.json`) and comparison figures are included. `tools/satoshin.py` crawls it politely for local use; it publishes no reuse licence. |
| Blocktrainer cross-check | [Blocktrainer's archive](https://www.blocktrainer.de/en/satoshi-nakamoto-full-archive) | Only links and comparison figures are included. `tools/blocktrainer.py` downloads its data for local use; it publishes no reuse licence, so ask Blocktrainer before republishing its German translations. |

## Name and logo

"Satoshi Mail", "Satoshipedia", "Satoshi Map" and their logos identify the official
project run by Tyler Howell ([@TylerHowell88](https://x.com/TylerHowell88)). The MIT
license lets you use and change the code; if you publish your own version, please
give it a different name and logo so people can tell it apart from the official one.

Satoshi Mail is an independent project. It is not affiliated with Google, Gmail,
Jmail, the Satoshi Nakamoto Institute, Blocktrainer, satoshin.name or any email provider.
